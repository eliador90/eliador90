# Hi, I'm Remo 👋

AI-native builder and entrepreneur based in Zurich, Switzerland.

I like starting things and running them myself, from a podcast to software
products. Lately it is mostly software: [Laudia](https://laudia.ai) is the
main one, a Swiss SaaS I am building into a business. Before this I managed
finances for startups and worked in venture capital.

## What I'm building

🏅 **[Laudia](https://laudia.ai)** — AI search visibility for the wellness
economy. When someone asks ChatGPT or Perplexity for the best in a
category, Laudia shows a brand where it actually stands, and what to fix to
change that. Free public audit (the Laudia Score) plus self-serve
monitoring for premium wellness, longevity and aesthetic brands. Under the
hood: Next.js, Supabase and Inngest on Vercel, with Swiss data residency.
Solo-built, launched early August 2026.

🚀 **[remotli.ch](https://remotli.ch)** — Switzerland's home for
remote-friendly jobs. Live and growing, solo-built and near-fully
automated: sourcing, classification and publishing all run without me.
